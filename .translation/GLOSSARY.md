# Словарь и правила перевода

Обязателен для каждого, кто переводит или синхронизирует файлы. Утверждён 2026-10-15.
Для кого перевод: читатель не знает английского и должен понять урок и выполнить задание только по-русски.
Поэтому любой английский текст, который не виден на экране Claude Code дословно, — переводить.

## Общие правила

1. **Что видно в интерфейсе Claude Code — не переводить.** Claude Code работает на английском, читатель
   сверяет урок с экраном. Пункты меню, надписи строки состояния, вкладки, сообщения об ошибках, вывод
   команд — как в оригинале, в `**жирном**` или `` `коде` ``. При первом упоминании в уроке можно дать
   перевод в скобках: **Yes, manually approve edits** (да, одобрять правки вручную).
2. **Не переводить:** код, команды, флаги, пути, имена файлов и папок, ключи конфигов, переменные
   окружения, текст внутри блоков кода (`bash`, `json`, `yaml`), URL, имена продуктов.
3. **Промпты в блоках `text`** (что читатель вводит в Claude Code) — всегда переводить на русский:
   Claude понимает русский. Имена файлов, функций и команд внутри промпта не трогать.
4. **Ссылки:** адрес не менять. Текст ссылки на документацию Anthropic — переводить по смыслу
   (`[Быстрый старт](…/quickstart)`), на страницы этого руководства — по переведённому заголовку.
   В строке `Sources:` названия страниц документации оставлять английскими (так их проще найти).
5. **Якоря.** Английские слаги всех заголовков уже закреплены скриптом `.translation/tools/pin-anchors.mjs`:
   `<a id="…"></a>` стоит строкой над заголовком `##`/`###`, а у H1 — в конце строки заголовка.
   Все `<a id>`/`<a name>` сохранять как есть, ничего не удалять и не переводить в них. Ссылки
   вида `файл.md#you-need` не менять — они указывают на эти якоря. Новые якоря не добавлять.
6. **Типографика:** длинное тире «—» в русском тексте — норма (правило `em-dash` оригинала к переводу
   не применяется). Кавычки «ёлочки», внутри — „лапки“. Буква «ё» — по желанию, без обязательности.
7. **Обращение — на «вы»** (со строчной), тон спокойный, деловой, как у оригинала. Короткие фразы.
   Не калькировать: «By the end of this lesson you can…» → «После урока вы умеете…».
8. **Числа, версии, даты** — как в оригинале; даты в формате оригинала (2026-10-05).
9. Строка штампа (строка `<sub>` под H1) переводится по шаблону, версия и дата — без изменений:
   - `<sub>**Начальный уровень** · Урок 1 из 5 · около 20 минут · Нужно: [ссылка](…) · Проверено на Claude Code v2.1.285 (stable) 2026-10-05</sub>`
   - `Elective` → `Дополнительный урок`; `Capstone` → `Итоговый проект`; `about 20 minutes, plus run time` →
     `около 20 минут плюс время запуска`; `30 to 60 minutes` → `от 30 до 60 минут`.
   - Часть `Проверено на Claude Code vX.Y.Z (stable) YYYY-MM-DD` писать точно так — её читает проверка `stamps`.
11. **Ссылки на внешние ресурсы не менять** (шаблон практики, issues и т. п.) — их заменит контроллер
    одним скриптом после перевода.
12. **Мёртвые зоны:** текст внутри HTML-комментариев `<!-- … -->` не переводить. Атрибуты `alt` у
    картинок — переводить.
10. Чек-лист проверки (`- [ ]`) — переводить; строки, которые сверяет `npm run check`, — это пути
    и вывод команд, они и так не переводятся.
