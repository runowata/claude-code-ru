# Бриф: перевод страниц руководства на русский

Репозиторий: `/Users/alexbel/Desktop/Проекты/claude-code-ru` (форк англоязычного руководства по Claude Code).
Читатель не знает английского: он должен понять урок и выполнить задание только по-русски.

## Перед началом
1. Прочитай `.translation/GLOSSARY.md` целиком — это обязательные правила и термины.
2. Образец готового перевода: `docs/beginner/01-install-and-look-around.md` (прочитай один раз, чтобы взять тон
   и оформление). Больше ничего «для контекста» не читай.

## Как работать с каждым файлом из твоего списка
1. Прочитай файл целиком (`Read`).
2. Перепиши его по-русски одним `Write`: тот же Markdown, та же структура, те же строки кода, ссылки, якоря.
   - Все `<a id="…"></a>` и `<a name="…">` оставить байт в байт на своих местах.
   - Блоки кода (```bash, ```json и т. д.) не трогать, кроме блоков ```text с промптами — их переводить.
   - Надписи интерфейса Claude Code (меню, строка состояния, вкладки, сообщения) — как в оригинале,
     при первом упоминании на странице можно дать перевод в скобках.
   - Строка `<sub>` под H1 (штамп) — строго по п. 9 словаря.
   - Ссылки на другие страницы руководства: текст ссылки — по-русски, адрес не менять.
   - Строки «Sources:» → «Источники:», названия внешних страниц внутри них оставить английскими.
   - Длинное тире в русском тексте разрешено.
3. Сверка после записи (один вызов Bash на файл):
   `diff <(grep -o '<a [^>]*>' ORIG) <(grep -o '<a [^>]*>' FILE)` где ORIG — `git show HEAD:путь` во временный файл,
   и то же для количества строк с ``` (`grep -c '^ *```'`) и количества `](` — числа должны совпасть.
   Если не совпало — исправь.

## Ограничения
- Трогай только файлы из своего списка. Не коммить, не делай `git add`, не запускай Docker.
- Не меняй адреса ссылок, имена файлов, код, команды, флаги.
- Потолок: 45 вызовов инструментов. Если не успеваешь — закончи текущий файл и перечисли остаток в отчёте.

## Отчёт
Запиши в `.translation/reports/<твой-id>.md`: таблица «файл | готово/нет | заметки» и отдельным списком места,
где сомневался в переводе или где смысл оригинала неясен. В ответе — только одна строка статуса.
