## Что переводить
Только строки, которые видит пользователь: подписи, подсказки при FAIL, заголовки, `title`, `text` пунктов
проверки, сообщения об ошибках приложения. Обращение на «вы».

## Что НЕ трогать
- Логику, имена переменных, ключи объектов, регулярные выражения, значения, с которыми сравнивается
  вывод программ (например, строки, которые ищутся в выводе `claude`, git, npm).
- Комментарии в коде — можно оставить английскими (ученик их не видит).
- `src/`, `test/`, `samples/` — это учебный проект, на нём ученик тренируется, его не трогать.
- `learn/lessons/*.md` — это отдельная задача, не твоя.

## Тесты
Тесты в `checks/test/` могут сверять английский текст подсказок. После перевода запусти свой набор тестов
(см. задание), и если тест падает только из-за изменённого текста — поправь ожидаемый текст в тесте.
Если падает по другой причине — откати свою правку, которая это вызвала. Полный `npm run test:checks` —
один раз в конце.
