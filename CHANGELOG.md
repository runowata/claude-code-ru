# Журнал изменений <a id="changelog"></a>

Выпуски руководства, новые сверху. Выпуск помечается тегом `vYYYY.MM`, а исправление между выпусками — `vYYYY.MM.N`. Каждый выпуск остаётся доступным по своему тегу.

<a id="unreleased"></a>
## Не выпущено

Базовая версия: Claude Code v2.1.285 (stable), зафиксирована 2026-10-05.

Каждое изменение следующего выпуска проверено на этой версии — теге `stable` пакета [`@anthropic-ai/claude-code`](https://www.npmjs.com/package/@anthropic-ai/claude-code?activeTab=versions) на 2026-10-05. Она остаётся замороженной до выхода выпуска, если только более поздний релиз `stable` не удалит, не переименует или не изменит по умолчанию то, чему учит урок.

Выпуски 2 и 3: Средний и Продвинутый путь с проверяемыми упражнениями. Все уровни теперь собраны заново, ни одной страницы прошлого выпуска не осталось.

<a id="added"></a>
### Добавлено

- [Средний уровень](docs/intermediate/README.md): восемь уроков — от первого skill до плагинов, через память проекта, модель и effort, разрешения и песочницу, hooks, субагентов и MCP, плюс итоговый проект, который готовит репозиторий к приходу нового коллеги. У каждого урока и итогового проекта есть проверка в [шаблоне для практики](https://github.com/runowata/claude-code-practice-ru). Проверки уроков можно запускать на своём репозитории через `--dir`; итоговый проект запускается в учебной копии шаблона.
- Четыре дополнительных урока Среднего уровня: [шаблоны skills](docs/intermediate/electives/skill-patterns.md), [Claude in Chrome](docs/intermediate/electives/claude-in-chrome.md), [status line](docs/intermediate/electives/status-line.md) и [fast mode](docs/intermediate/electives/fast-mode.md).
- [Примеры](examples/README.md) для уроков Среднего уровня: два skills, три скрипта hooks, субагент-рецензент только для чтения и закреплённая по версии конфигурация MCP-сервера Chrome DevTools. Каждый пример неактивен, пока вы не скопируете его в проект, и снабжён смоук-тестом.
- [Продвинутый уровень](docs/advanced/README.md): семь уроков — от параллельных сессий в worktrees до границ для автономных запусков, через паттерны оркестрации, динамические workflows, скрипты на `claude -p`, GitHub Actions и общую с командой настройку, плюс итоговый проект, который добавляет CI-рецензию для всей команды. У каждого урока и итогового проекта есть проверка в [шаблоне для практики](https://github.com/runowata/claude-code-practice-ru). Большинство проверок уроков запускается на вашем репозитории через `--dir`; урок про GitHub Actions и итоговый проект запускаются в отдельной учебной копии шаблона, которую потом удаляют.
- Пять дополнительных уроков Продвинутого уровня: [agent teams](docs/advanced/electives/agent-teams.md), [agent view](docs/advanced/electives/agent-view.md), [`/goal`, `/loop` и routines](docs/advanced/electives/goal-loop-routines.md), [проверка и публикация плагина](docs/advanced/electives/publish-a-plugin.md) и [dev-контейнеры](docs/advanced/electives/dev-containers.md).
- [За пределами руководства](docs/advanced/beyond-this-guide.md): куда идти, чтобы строить собственных агентов и MCP-серверы, а также запускать и внедрять Claude Code в организации.
- [Примеры](examples/README.md) для Продвинутого уровня: marketplace `team-tools` с плагином `team-kit` (skill `onboard` и субагент `config-reviewer` только для чтения) и настройки, которые им делятся, а также субагенты `security-reviewer` и `test-reviewer` только для чтения для дополнительного урока про agent teams. Каждый пример неактивен, пока вы не скопируете его в проект, и снабжён смоук-тестом.

<a id="changed"></a>
### Изменено

- Анимированный талисман Claude снова рядом с заголовком README, а социальная карточка показывает его вместо трёх тропных меток. Он взят из [shanraisshan/claude-code-best-practice](https://github.com/shanraisshan/claude-code-best-practice) под лицензией MIT.
- Страницы тем, [Команды по уровням](docs/reference/commands.md) и [Карта возможностей](docs/reference/feature-map.md) ссылаются на уроки и дополнительные уроки Среднего и Продвинутого уровней, а раздел «Что когда использовать» в [оглавлении Среднего уровня](docs/intermediate/README.md#when-to-use-what) ссылается на урок про динамические workflows.
- docs/reference/effort-levels.md и docs/skills.md теперь заглушки, которые ведут на уроки и справочные страницы, заменившие их; заглушки `mcp-servers/` и `specialized-agents/` ведут на уроки про MCP и субагентов.
- docs/agent-teams.md, docs/workflows.md и docs/reference/faq.md теперь заглушки, которые ведут на уроки, дополнительные уроки и справочные страницы, заменившие их.
- Проверка `inertness` теперь падает и на манифесте marketplace в примере, который не переименован в `dot-claude-plugin/`, и на папке `.claude-plugin/` в корне репозитория. Проверка `static-validation` теперь охватывает также skills и агентов плагинов из marketplace в примерах.

<a id="v202610---2026-10-05"></a>
## v2026.10 - 2026-10-05

Проверено на Claude Code v2.1.285 (stable).

Выпуск 1: Начальный путь с проверяемыми упражнениями и структура, на которой строятся следующие два уровня. Средний и Продвинутый уровни пересобираются; копии разделов README прошлого выпуска про skills, hooks, субагентов и параллельную работу, MCP и fast mode остаются доступными в `docs/legacy/` с пометкой, что ещё не перепроверены.

<a id="added-1"></a>
### Добавлено

- [Начальный уровень](docs/beginner/README.md): пять уроков — от установки Claude Code до памяти проекта, итоговый проект и три дополнительных урока. У каждого урока и итогового проекта есть проверка, которую вы запускаете в [шаблоне для практики](https://github.com/runowata/claude-code-practice-ru); ветка `solutions` шаблона проходит все проверки.
- Входная страница, которая направляет вас на нужный уровень, и оглавления трёх уровней, [тем](docs/topics/README.md) и [справочных страниц](docs/reference/README.md), включая [Карта возможностей](docs/reference/feature-map.md) и [глоссарий](docs/reference/glossary.md).
- Страницы прошлого выпуска остаются доступными в `docs/legacy/` с пометкой, пока не появятся заменяющие их уроки.
- Формы issue для проблем с уроком, ошибок и устаревших фактов, а внизу каждого урока — ссылка «Застряли на уроке?».
- Проверки каждого pull request: внутренние ссылки и якоря, штампы страниц, структура уроков, изображения, длинные тире, проверка конфигурации и безопасность `examples/`. Плановые проверки следят за внешними ссылками, маркерами устаревания и новыми релизами `stable` и открывают issue, когда что-то требует внимания.
- Политика листингов в [CONTRIBUTING.md](CONTRIBUTING.md#listing-policy) и форма для предложения ресурса.
- Правила для агентов в [AGENTS.md](AGENTS.md), которые подключает новый [CLAUDE.md](CLAUDE.md).
- Переписанный [CONTRIBUTING.md](CONTRIBUTING.md), шаблон pull request с таблицей утверждений и разделом о пробном прогоне, а также файл CODEOWNERS.

<a id="changed-1"></a>
### Изменено

- Заморозка листингов закончилась: предложения ресурсов снова рассматриваются по [планке листингов](CONTRIBUTING.md#the-listing-bar).
- У руководства теперь собственный знак — три тропные метки, поднимающиеся по столбу, — вместо изображения талисмана, чтобы не использовать образ персонажа Anthropic. К нему прилагается новая социальная карточка, на которой нет ничего, что может устареть.
- Справочные страницы переписаны для поиска нужного: [Модели и effort](docs/reference/models.md), [Команды по уровням](docs/reference/commands.md) и [Что читать дальше](docs/reference/further-reading.md). В них нет цен, лимитов тарифов и спецификаций моделей, а для них даны ссылки на официальные страницы.

### Удалено

<a id="removed-listings"></a>

Что руководство перечисляет теперь, говорит [политика листингов](CONTRIBUTING.md#listing-policy). Старые ссылки на эти страницы и разделы ведут на строку, которая об этом сообщает.

<a id="removed-further-reading-listings"></a>
- Из раздела «Что читать дальше»: анонсы моделей, калькулятор токенов, примеры сторонних MCP-серверов и пост про аутентификацию MCP, подборки hooks и workflows, терминальные и заметочные инструменты, другой ассистент для кода и анонс совместимости агентов. Ни один урок их не использует.

<a id="removed-live-config"></a>
- Живая настройка Claude Code в репозитории больше ничего не запускает, когда вы клонируете репозиторий и доверяете папку. Убрано: озвученный hook Notification со скриптами синтеза речи и помощника на LLM, 14 allow-правил, пять персон субагентов в `.claude/agents/`, семь слэш-команд в `.claude/commands/`, а также каталог skills и рецепты workflows в docs/skills.md, которые их описывали. В `.claude/` остались правило deny на чтение файлов `.env`, skill claude-md-review и workflow stale-docs-audit. Чтобы сохранить собственное звуковое уведомление, добавьте hook Notification в `~/.claude/settings.json`.
