# Что читать дальше <a id="further-learning"></a>

<sub>Проверено на Claude Code v2.1.285 (stable) 2026-10-05</sub>

Курсы, документация и статьи, которые идут глубже руководства, сгруппированные по уровню, где они полезнее всего. Уроки ссылаются на страницы, на которые опираются; здесь собрано остальное. Все материалы опубликованы Anthropic, кроме спецификации Agent Skills — открытого стандарта, который начала Anthropic.

Материалы сверены с планкой для списков 2026-10-05.

## С чего угодно начать

- [Claude Code overview](https://code.claude.com/docs/en/overview) (обзор Claude Code): что это и где работает.
- [Best practices](https://code.claude.com/docs/en/best-practices) (лучшие практики): советы Anthropic по работе с Claude Code.
- [What's new](https://code.claude.com/docs/en/whats-new): еженедельный дайджест заметных новых возможностей.
- [CLI reference](https://code.claude.com/docs/en/cli-reference): все флаги командной строки.
- [Claude Code user FAQ](https://support.claude.com/en/articles/14554922-claude-code-user-faq): ответы из Справочного центра Anthropic.
- [Models overview](https://platform.claude.com/docs/en/about-claude/models/overview) и [тарифы и цены](https://claude.com/pricing). Страница руководства [Модели и effort](models.md) описывает псевдонимы и уровни effort.

## Начальный уровень

- [Quickstart](https://code.claude.com/docs/en/quickstart) (быстрый старт): от установки до первого изменения.
- [Commands](https://code.claude.com/docs/en/commands) (команды): все встроенные команды. В [Команды по уровням](commands.md) из руководства перечислены те, что используют уроки.

## Средний уровень

- [Hooks reference](https://code.claude.com/docs/en/hooks) (справочник по hooks): каждое событие hook, его вход и выход.
- [Troubleshooting](https://code.claude.com/docs/en/troubleshooting) (устранение неполадок) и [справочник ошибок](https://code.claude.com/docs/en/errors): когда настройка ведёт себя не так.
- [Fast mode](https://platform.claude.com/docs/en/build-with-claude/fast-mode): сторона API у fast mode.
- [How Anthropic teams use Claude Code](https://claude.com/blog/how-anthropic-teams-use-claude-code) (как команды Anthropic используют Claude Code): как с ним работают внутри Anthropic.
- [Onboarding Claude Code like a new developer](https://claude.com/blog/onboarding-claude-code-like-a-new-developer-lessons-from-17-years-of-development) (вводим Claude Code в проект как нового разработчика): как один проект с открытым кодом настроил Claude Code для своей большой кодовой базы.
- [Maximizing the value of your Claude Code sessions](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions) (как получить от сессий Claude Code максимум) и [Claude Code power user tips](https://support.claude.com/en/articles/14554000-claude-code-power-user-tips) (советы опытным пользователям).
- [How Claude Code is used in practice](https://www.anthropic.com/research/claude-code-expertise) (как Claude Code используют на практике): исследование Anthropic о том, как люди с ним работают.
- По MCP официальная документация перечислена на [странице темы MCP](../topics/mcp.md).

## Продвинутый уровень

- [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) (создаём эффективных агентов): шаблоны Anthropic для агентных систем.
- [Agent Skills specification](https://agentskills.io/specification) (спецификация Agent Skills): открытый формат, которому следуют skills Claude Code.
- [Set up Claude Code in a monorepo or large codebase](https://code.claude.com/docs/en/large-codebases) (настраиваем Claude Code в монорепозитории или большой кодовой базе): вложенные файлы CLAUDE.md, разреженные worktrees и skills для отдельных пакетов.
- [How Anthropic runs large-scale code migrations with Claude Code](https://claude.com/blog/ai-code-migration) (как Anthropic проводит масштабные миграции кода с Claude Code).
- [Code w/ Claude talks](https://claude.com/blog/code-w-claude-sf-2026-sf) (выступления Code w/ Claude): обзор и записи докладов.
